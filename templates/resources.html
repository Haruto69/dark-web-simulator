Ten habits of digital safety

  1. Never enter real credentials on a suspicious site, even for testing.
  2. Use strong, unique passwords managed by a password manager.
  3. Enable two-factor authentication on every critical account.
  4. Install security patches promptly.
  5. Back up data regularly -- 3 copies, 2 media, 1 offsite.
  6. Be skeptical of manufactured urgency.
  7. Verify links and sender identity before clicking.
  8. Keep reputable security software installed and current.
  9. Keep learning -- tactics evolve continuously.
  10. Report suspicious activity to IT or the relevant authority.

Quick reference

Red flags

  • Urgent language
  • Misspelled or lookalike URLs
  • Requests for credentials
  • Too-good-to-be-true offers
  • Generic greetings
  • Unexpected attachments

Green flags

  • HTTPS and a valid certificate
  • Exact domain match
  • Personalized, expected content
  • No credential requests
  • Verifiable sender
